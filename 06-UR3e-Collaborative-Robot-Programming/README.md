# UR3e Collaborative Robot Programming

## Overview

This project was completed as part of **ITAI 2374 – Robotics and AI Platforms** at Houston City College. Throughout multiple laboratory sessions, our team learned to configure, program, and operate a Universal Robots UR3e collaborative robot (cobot) using the PolyScope interface, a Hand-E gripper, and a Dorner 2200 Series conveyor.

The project progressed from foundational robot setup and waypoint programming to implementing an automated pick-and-place system using sensor-based logic and conveyor integration.

---

## Project Objectives

The objectives of this project were to:

- Configure and initialize the UR3e collaborative robot.
- Learn the PolyScope programming environment.
- Configure the Tool Center Point (TCP) and payload settings.
- Create waypoint-based robot programs.
- Integrate a Hand-E gripper with the robot.
- Develop an automated pick-and-place sequence.
- Apply sensor-based logic to industrial automation tasks.

---

## Phase 1 – Robot Configuration and Basic Programming

During the first laboratory session, our team focused on learning the fundamentals of operating the UR3e collaborative robot.

Activities included:

- Robot initialization
- Teach Pendant operation
- PolyScope interface navigation
- Tool Center Point (TCP) calibration
- Orientation configuration
- Payload and Center of Gravity setup
- Waypoint programming
- Home position configuration
- Safe robot operation

## Phase 2 – Advanced Automation

Building on the initial setup, our midterm project expanded the robot's capabilities by implementing a more advanced automated pick-and-place process.

The project included:

- Multi-waypoint programming
- Hand-E gripper integration
- Object detection logic
- Conditional ("If object detected") programming
- Conveyor synchronization
- Automated pick-and-place cycle
- Sensor calibration
- Program optimization

The completed system enabled the UR3e to detect, pick, and place objects while interacting with the conveyor system through sensor-based automation. :contentReference[oaicite:1]{index=1}

## Challenges and Troubleshooting

Throughout the project we encountered several technical challenges, including:

- TCP orientation calibration
- Payload and Center of Gravity adjustments
- Protective stops caused by incorrect payload settings
- Sensor sensitivity calibration
- Operational mode permissions
- Waypoint precision
- Conveyor synchronization

By carefully adjusting robot parameters and applying the concepts learned during training, our team successfully resolved these issues and achieved reliable robot operation. :contentReference[oaicite:2]{index=2}
