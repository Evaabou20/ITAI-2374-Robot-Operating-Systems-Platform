# Raspberry Pi System Setup and AI Presentations

## Overview

This project was completed as part of **ITAI 2374 – Robotics and AI Platforms** at Houston City College. The assignment introduced our team to the Raspberry Pi platform through a series of hands-on hardware configuration activities and AI-generated presentations.

The project combined embedded systems, hardware troubleshooting, multimedia configuration, and AI communication tools to demonstrate practical robotics and AI platform skills.

---

## Project Objectives

The objectives of this assignment were to:

- Configure and boot a Raspberry Pi system.
- Install and test Raspberry Pi peripherals.
- Configure audio and camera devices.
- Install and troubleshoot the Sense HAT module.
- Explore AI-powered video generation using Synthesia.
- Practice communicating technical concepts through AI-generated presentations.

---

## Raspberry Pi Hardware Activities

The technical report documents the following activities:

- Raspberry Pi OS installation and initial system setup.
- Hardware configuration and boot process.
- Audio output configuration using a JBL speaker.
- Camera configuration using the Cheese application.
- Sense HAT installation and GPIO alignment.
- Hardware troubleshooting using Linux command-line tools.
- Documentation of the setup with photographs and technical explanations.

---

## AI Video Presentations

### AI in Everyday Life

Our team created an educational video using **Synthesia** explaining how artificial intelligence is used in everyday life. The presentation highlights practical AI applications and demonstrates how AI-generated avatars can be used to communicate technical concepts in an engaging way.

### Intel Professional Interview

As part of this assignment, our class was scheduled to attend a guest presentation by an Intel professional at Houston City College. Since our team was unable to attend the session, we created an AI-generated interview using **Synthesia**. The presentation simulated asking questions about Intel, including topics related to the company, career opportunities, internships, and the professional experience of working at Intel. This activity allowed us to practice using AI-generated avatars to communicate technical and career-related information.
