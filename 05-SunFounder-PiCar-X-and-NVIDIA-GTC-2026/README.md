# SunFounder PiCar-X Robot and NVIDIA GTC 2026

## Overview

This project was completed as part of **ITAI 2374 – Robotics and AI Platforms** at Houston City College. The assignment combined hands-on robotics with current developments in artificial intelligence by integrating a Raspberry Pi 5 with a SunFounder PiCar-X robot and analyzing sessions from the NVIDIA GTC 2026 conference.

The project provided practical experience configuring robotic hardware, troubleshooting embedded systems, and exploring the latest advances in AI infrastructure, robotics, and agentic AI.

---

## Project Objectives

The objectives of this assignment were to:

- Configure and initialize the SunFounder PiCar-X robot.
- Integrate the Raspberry Pi 5 with the robot hardware.
- Configure software interfaces and Python libraries.
- Execute and test robot movement using Python.
- Troubleshoot hardware and software issues.
- Explore current AI innovations presented at NVIDIA GTC 2026.
- Analyze emerging technologies in artificial intelligence and robotics.

---

## Part 1 – SunFounder PiCar-X Robot

Our team configured a Raspberry Pi 5 to operate the SunFounder PiCar-X robot. Since the robot was already assembled, the focus of the lab was software configuration, hardware integration, and system testing rather than physical assembly.

The project included:

- Raspberry Pi 5 initialization
- I2C interface configuration
- Linux system updates
- SunFounder software installation
- Python-based robot movement testing
- Steering calibration
- Hardware troubleshooting
- Camera diagnostics
- Collaborative debugging

Although the robot's camera module was determined to be non-functional, the remaining systems—including locomotion, steering, and motor control—were successfully configured and tested. The completed robot demonstrated reliable movement using Python scripts executed on the Raspberry Pi. :contentReference[oaicite:0]{index=0}
