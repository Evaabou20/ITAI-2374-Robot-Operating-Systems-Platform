# Raspberry Pi Research

## Project Overview

This team research assignment introduced the Raspberry Pi ecosystem through the Raspberry Pi Official Magazine (Issue 161). Working as Team EVO, we explored Raspberry Pi hardware, software, and educational applications while developing a foundational understanding of embedded computing and robotics.

Each team member researched different topics from the magazine and reflected on how Raspberry Pi supports programming, Linux, electronics, and real-world engineering projects.

---

## Learning Objectives

- Explore the Raspberry Pi ecosystem
- Understand Raspberry Pi hardware and software
- Learn the role of Raspberry Pi in robotics and embedded systems
- Develop technical research and reading skills
- Collaborate as a team to summarize technical concepts

---

## Topics Covered

- Raspberry Pi hardware
- Raspberry Pi OS
- Raspberry Pi Imager
- GPIO pins
- Python programming
- Linux
- Embedded systems
- Robotics
- Team collaboration

## Key Learning Outcomes

This assignment introduced the Raspberry Pi as an affordable single-board computer capable of running Linux, supporting Python programming, and interfacing with hardware through GPIO pins. It also demonstrated how Raspberry Pi serves as a versatile platform for robotics, embedded systems, and hands-on engineering education while strengthening collaborative research and technical communication skills.
